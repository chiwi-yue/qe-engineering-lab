# Problem

What behaviour or symptom was observed? Label deliberate defects clearly.

# Requirement

What should the system do?

# Risk

Why does this matter?

# Reproduction

List prerequisites, data, exact commands and steps.

# Evidence

Link actual logs, responses, database state, traces, screenshots or metrics. Include execution date and environment. Distinguish observations from hypotheses.

# Investigation

What hypotheses were considered and how were they tested?

# Root cause

What actually caused the problem? What evidence supports that conclusion?

# Fix

What changed and why?

# Regression protection

Which automated check detects recurrence? Demonstrate failure before the fix and success after it where practical.

# Remaining risks

What is not covered? What trade-offs remain?

# Interview summary

Explain requirement, risk, investigation, fix and limitations in approximately 60–90 seconds.
