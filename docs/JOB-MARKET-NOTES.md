# Job-market alignment

These priorities come from the project brief, not a fresh survey of Australian job advertisements:

1. Playwright
2. TypeScript
3. API automation
4. CI/CD
5. SQL/database validation
6. Risk-based testing
7. Debugging
8. Performance
9. Cloud/container literacy
10. Evaluated AI-assisted QE

When reviewing roles, record source URL, date, role/seniority, recurring signals and portfolio evidence gaps. Look for patterns across multiple relevant roles. Do not rewrite the architecture around a single advertisement or add technologies solely for keywords.
